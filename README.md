# Python代码反模式和安全问题示例

这个项目展示了Python代码中常见的反模式（Anti-patterns）和安全问题，以及它们的正确解决方案。

## 代码问题分类

### 1. 安全漏洞
- **SQL注入**：直接拼接SQL语句，允许攻击者执行恶意SQL命令
- **XSS攻击**：不安全的HTML生成，允许注入恶意脚本
- **不安全的文件操作**：未经验证的文件路径访问
- **不安全的密码处理**：明文存储密码
- **不安全的配置管理**：硬编码敏感信息

### 2. 代码质量问题
- **不安全的异常处理**：捕获所有异常且不记录
- **不安全的并发处理**：使用全局变量进行线程间通信
- **不安全的输入验证**：缺少输入验证
- **不安全的资源管理**：未使用上下文管理器
- **不安全的日志记录**：记录敏感信息

## 最佳实践建议

### 1. 数据库操作
- 使用参数化查询而不是字符串拼接
- 使用ORM框架（如SQLAlchemy）
- 实施适当的访问控制

### 2. Web安全
- 使用HTML转义函数处理用户输入
- 实施CSRF保护
- 使用安全的会话管理

### 3. 文件操作
- 验证文件路径
- 使用安全的文件权限
- 实施文件类型检查

### 4. 密码安全
- 使用加密哈希存储密码
- 使用随机盐值
- 实施密码复杂度要求

### 5. 异常处理
- 具体捕获异常
- 记录异常信息
- 实施适当的错误恢复机制

### 6. 并发处理
- 使用线程安全的数据结构
- 使用锁机制
- 避免共享状态

### 7. 配置管理
- 使用环境变量
- 使用配置文件
- 避免硬编码敏感信息

### 8. 输入验证
- 验证输入类型
- 验证输入长度
- 验证输入格式

### 9. 资源管理
- 使用上下文管理器（with语句）
- 及时释放资源
- 实施超时机制

### 10. 日志记录
- 不记录敏感信息
- 使用适当的日志级别
- 实施日志轮转

## 使用说明

1. 查看 `code_anti_patterns.py` 文件中的示例代码
2. 每个示例都包含了问题代码和正确的解决方案
3. 运行示例代码（不推荐在生产环境中运行）

## 安全建议

1. 定期进行安全审计
2. 使用安全扫描工具
3. 保持依赖包更新
4. 实施安全编码规范
5. 进行安全培训
